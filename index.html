Why this fix?
Some Watson integrations can throw "Failed to track events" when event-tracking functions are missing or throw errors in your environment. This page wraps event-tracking with safe guards, provides graceful error handling, and shows a functional local fallback chat so users can continue interacting.

- If you see tracking errors, this page will log them and use the fallback chat. Check console for details.
